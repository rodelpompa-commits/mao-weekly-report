# MAO Weekly Report

Official upgraded weekly itinerary and accomplishment reporting app for the Municipal Agriculture Office.

## What This Version Includes

- Staff itinerary planning from Monday to Friday
- Accomplishment encoding based on planned itinerary
- Shared central storage so Android, Windows, and browser users see the same records
- Server-side login checking
- Admin dashboard with staff performance summary
- Technical assistance grading based on applicable crop stage
- Field photo and location support
- Consolidated field map
- Print and download support

## Staff Install Files

The latest install files are kept in `release-files/`.

- Android phones: `release-files/MAO-Weekly-Report.apk`
- Laptop/Desktop: `release-files/MAO-Weekly-Report-Windows.zip`

For Windows users, unzip `MAO-Weekly-Report-Windows.zip`, then open `MAO Weekly Report.exe`.

## Live App

The app currently loads the deployed online system internally. The Android APK and Windows app are wrappers around the live system, so future online fixes usually do not require reinstalling the app unless the icon, app name, or app wrapper itself changes.

## Important

Keep this repository private because it contains server-side setup code for the official staff access system.
